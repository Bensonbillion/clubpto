ClubPTO · Manage

Mobile wireframes, the court manager

Every frame is 390px wide. Nights are named by day only, no venue. Dark ground, one deep green accent, restrained red for destructive actions only. Inter for functional text, VT323 for every numeral, Playfair for the session title and the champion. Assumptions made: accent green resolved to #4E9B63 (swap it in Tweaks), fixture roster of 15 named players over 2 courts, unconfirmed details kept as visible [[TOKENS]]. The bracket frame is shown with a 16 player court so the quarterfinal stage appears.
