# A frame 11 — Balance rule

```
11
Balance rule
· why this four
Why this four
Round 2 · Court 1
Least played, first on
Chizea, Ayo, Abiola and Timi had played the fewest games, so they are on. Nobody on this court is ever more than one game behind.
Never the only newcomer
Chizea is C-tier, so Abiola is across the net rather than alongside. No game becomes three players hunting the weak fourth.
One court for everyone
When the whole group shares a court, the A-and-B mixing stays as it is, and C plays only with other Cs or with one B — never in a game with an A.
This is why the courts do not need to be pure. A gradient court still gives everyone a good night.
```
